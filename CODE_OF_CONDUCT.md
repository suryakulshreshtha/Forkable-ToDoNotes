# 💜 Code of conduct

This is a place to learn. Everyone here was a beginner at something.

- **Be kind.** Critique code, never people.
- **Be patient.** "Obvious" is only obvious once you know it.
- **Be honest.** Say "I don't know" and "I was wrong" freely.
- **Be inclusive.** No harassment, insults or discrimination of any kind.

Problems can be reported privately to the maintainer through the contact
details on the [maintainer's GitHub profile](https://github.com/suryakulshreshtha).
Unacceptable behaviour can lead to removal from the project's spaces.
